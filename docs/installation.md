---
title: Installation
---

```sh
pnpm add @tanstack/redact
```

Keep your existing React dependencies and framework plugins. Your application continues importing from `react` and `react-dom`. Choose the integration for your framework, it handles the runtime replacement.

Follow [Quick Start](./quick-start.md) for Vite, [Next.js](./next.md), or [Vinext](./vinext.md). No application-wide import rewrite is needed.
